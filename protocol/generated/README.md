# Generated protocol types

`typescript-wire-types.ts`, `ruby-wire-types.rb`, and the compiled
`crates/app-bridge/src/wire.rs` are reproducible projections of protocol 1. Templates live in
`protocol/templates/`; the checked-in projections support SDK packaging and review.
Run `python3 protocol/conformance/generate.py --check` to verify them or omit `--check` to update.
